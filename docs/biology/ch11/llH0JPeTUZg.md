# Mean, Median, and Mode — Class 9 Biology Lecture Summary

## Lecture Overview
This lecture covers the three main Measures of Central Tendency—Mean, Median, and Mode—explaining how to calculate each one and when it is appropriate to use them for biological data.

## Main Concepts Explained by the Teacher
Sir defines measures of central tendency as values that represent the center of a data set. **Mean (Average):** Calculated by summing all values and dividing by the number of values. It is the most common measure but is sensitive to extreme values (outliers). Example: calculating average height of students. **Median:** The middle value when data is arranged in ascending or descending order. It is better for data with outliers. Example: average income or survival time after treatment. **Mode:** The most frequently occurring value. It is useful for categorical data (most common blood type, most common species in an area). The teacher demonstrates calculations with biological examples: plant heights, heart rates, and bacterial counts.

## Important Definitions and Terms
- **Mean (Average):** Sum of all values divided by the total number of values (x̄ = Σx/n).
- **Median:** The middle value when data is arranged in order (or average of two middle values).
- **Mode:** The value that appears most frequently in a data set.
- **Central Tendency:** A statistical measure that identifies a single value as representative of an entire distribution.
- **Outlier:** An extreme value that differs significantly from other observations.

## Key Points and Lists from the Lecture
- Mean is affected by outliers; median is not.
- Mode is useful for nominal (categorical) data.
- For symmetrical data, mean = median = mode.
- For skewed data (with outliers), median is more representative.
- Calculate mean for continuous data (height, weight, temperature).
- Calculate mode for discrete or categorical data (blood group, species type).

## What Students Should Remember
Honestly, knowing when to use mean vs. median is critical. If a dataset has extreme outliers (like one very tall person in a class), the median is a better measure of the "typical" value.
